Users can drag, scroll, use the keyboard, or type to jump to an option. The machine is built on [Zag](https://zagjs.com)
and will be contributed upstream as `@zag-js/wheel-picker`. Until then it ships as `@isbatak/zag-wheel-picker`.

- Mouse, touch, wheel, keyboard and typeahead
- Inertia scrolling that snaps to items
- Optional infinite looping
- Disabled items, controlled and uncontrolled values
- A hidden native select for forms
- RTL support

## Usage

A complete, copy-pasteable component. It is the same code that runs in the preview.

<ExampleCode id="wheel-picker-basic" />

The wheel renders two synchronized layers. `api.items` is the rotating 3D wheel. `api.highlightItems` is the selected
row, drawn inside the clipped highlight.

> Pass a unique `id` to the machine so generated element ids stay stable.

### Collection

Every item needs a `label` and a `value`, and can be `disabled`.

```ts
const collection = wheelPicker.collection({
  items: [
    { label: "React", value: "react" },
    { label: "Angular", value: "angular", disabled: true },
  ],
})
```

### Controlled value

Use `value` and `onValueChange` to own the state. `api.setValue` jumps to a value; `api.scrollToIndex` animates to it.

<Example id="wheel-picker-controlled" />

### Scroll events

`onScrollChange` fires while the centered item changes. `onValueChangeEnd` fires once the wheel settles.

```ts
const service = useMachine(wheelPicker.machine, {
  collection,
  onScrollChange: (details) => console.log("centered:", details.value),
  onValueChangeEnd: (details) => console.log("settled:", details.value),
})
```

### Infinite scrolling

`infinite` repeats the collection in both directions.

<Example id="wheel-picker-infinite" />

### Scroll feel

`dragSensitivity` sets how far the wheel coasts after a drag, `scrollSensitivity` how fast it steps. `optionItemHeight`
must match the rendered item height.

```ts
const service = useMachine(wheelPicker.machine, {
  collection,
  infinite: true,
  dragSensitivity: 5,
  scrollSensitivity: 5,
  optionItemHeight: 30,
})
```

### Forms

Set `name` and render the hidden select with every collection item. `disabled` blocks interaction and submission;
`readOnly` keeps the control focusable.

## Styling

Every part has `data-scope="wheel-picker"` and a `data-part` attribute. The machine sets the structural styles (3D
transforms, positions) inline, so your CSS only handles the look. The control exposes `data-focus`,
`data-focus-visible`, `data-dragging`, `data-scrolling`, `data-disabled`, `data-readonly` and `data-invalid`. Items
expose `data-selected` and `data-disabled`.

The stylesheet in the usage example is scoped to the `wheel-picker` class on the root, and reads these custom
properties, so you can theme it without editing it:

```css
:root {
  --wheel-picker-fg-color: #18181b;
  --wheel-picker-muted-color: #a1a1aa;
  --wheel-picker-highlight-color: #f4f4f5;
  --wheel-picker-ring-color: #a1a1aa;
  --wheel-picker-radius: 8px;
}
```

## Ark UI

`@isbatak/ark-wheel-picker` provides Ark UI style components for React, Solid, Vue and Svelte. They follow Ark's
conventions: `Root` and `RootProvider`, `asChild`, a `Context` render helper, and `useWheelPicker` /
`useWheelPickerContext`. They read `dir` and the root node from Ark's providers.

<ArkExample />

```tsx
import { createWheelPickerCollection, WheelPicker } from "@isbatak/ark-wheel-picker/react"

const collection = createWheelPickerCollection({
  items: [
    { label: "React", value: "react" },
    { label: "Vue", value: "vue" },
  ],
})

export const Demo = () => (
  <WheelPicker.Root collection={collection} defaultValue="react">
    <WheelPicker.Label>Framework</WheelPicker.Label>
    <WheelPicker.Control>
      <WheelPicker.Viewport>
        <WheelPicker.ItemGroup>
          <WheelPicker.Context>
            {(api) =>
              api.items.map(({ item, index, key }) => (
                <WheelPicker.Item key={key} item={item} index={index}>
                  {item.label}
                </WheelPicker.Item>
              ))
            }
          </WheelPicker.Context>
        </WheelPicker.ItemGroup>
        <WheelPicker.Highlight>
          <WheelPicker.HighlightItemGroup>
            <WheelPicker.Context>
              {(api) =>
                api.highlightItems.map(({ item, index, key }) => (
                  <WheelPicker.HighlightItem key={key} item={item} index={index}>
                    {item.label}
                  </WheelPicker.HighlightItem>
                ))
              }
            </WheelPicker.Context>
          </WheelPicker.HighlightItemGroup>
        </WheelPicker.Highlight>
      </WheelPicker.Viewport>
    </WheelPicker.Control>
    <WheelPicker.HiddenSelect />
  </WheelPicker.Root>
)
```

Swap the import for `@isbatak/ark-wheel-picker/solid`, `/vue` or `/svelte`. The parts are the same.

## Panda CSS

`@isbatak/panda-wheel-picker` ships the slot recipe used above. It builds on the semantic tokens of this design system
(`fg`, `bg.muted`, `colorPalette.*`, `l2` radii), so it works with any Chakra-style Panda preset.

```ts
import { wheelPickerPreset } from "@isbatak/panda-wheel-picker"
import { defineConfig } from "@pandacss/dev"

export default defineConfig({
  presets: ["@pandacss/preset-base", wheelPickerPreset],
})
```

Or extend your theme with the recipe directly:

```ts
import { wheelPickerRecipe } from "@isbatak/panda-wheel-picker"

export default defineConfig({
  theme: { extend: { slotRecipes: { wheelPicker: wheelPickerRecipe } } },
})
```

It has `variant` (`subtle`, `outline`, `solid`) and `size` (`sm`, `md`, `lg`) variants.

## Accessibility

The control has the `spinbutton` role and reports the current item through `aria-valuenow` and `aria-valuetext`. Give it
a name with a visible label, `aria-label` or `aria-labelledby`.

- **Arrow Up / Arrow Down**: select the previous or next enabled item
- **Arrow Left / Arrow Right**: move focus between sibling wheel pickers
- **Home / End**: select the first or last enabled item (not in infinite mode)
- **Characters**: jump to an item by typeahead
