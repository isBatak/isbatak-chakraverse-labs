This project hosts [Zag](https://zagjs.com) state machines that are developed outside the
[Zag repository](https://github.com/chakra-ui/zag) before they are contributed upstream.

Each machine holds the framework-agnostic logic of a UI component. Use it with the Zag adapter for your framework:
`@zag-js/react`, `@zag-js/vue`, `@zag-js/solid`, `@zag-js/svelte`, `@zag-js/preact` or `@zag-js/vanilla`.

## Machines

- [Wheel picker](/docs/components/wheel-picker): pick a value by scrolling a wheel of options
