# @isbatak/zag-wheel-picker

Stories for the wheel picker machine, rendered with every framework adapter zag supports. Each framework has its own
Storybook, and this Storybook combines them in the sidebar:

- React: `apps/storybook-react` (port 6007)
- Vue: `apps/storybook-vue` (port 6008)
- Svelte: `apps/storybook-svelte` (port 6009)
- Solid: `apps/storybook-solid` (port 6010)
- Preact: `apps/storybook-preact` (port 6011)
- Vanilla: `apps/storybook-vanilla` (port 6012)

Run `pnpm storybook` from the repository root to start all of them; this one opens on port 6006.

Shared styles, collections, controls and time helpers live in `apps/storybook-shared`.
